# Prosjektregler

- Prosjektrot er denne mappen. Bruk prosjekt-relative stier.
- Ikke opprett ChatGPT Sites-prosjekt eller Sites-konfigurasjon.
- Første offentlige forhåndsvisning kan publiseres kontrollert til GitHub Pages under ltj54.
- Ingen automatisk commit eller push. Etter første publisering kreves ny uttrykkelig bestilling fra Lars.
- Kundens e-post, fakturaer, private bilder og interne avtaleutkast skal ikke legges i offentlig Git-repository.
